## 状态与异步契约

- 保存确认被替换、编辑器关闭、渠道切换或组件卸载时，未完成的决策以取消结束。
- 显式确认只消费当前 resolver 一次；随后的弹窗关闭事件不会改写已经作出的决策。
- 凭据请求发出后即使编辑器关闭或渠道切换，迟到的响应也不能显示在新会话中。
- 切换渠道会取消旧的安全验证流程。Re-authorize 保留服务端 proof 校验。
- 因子状态请求失败表示“未知”，不会被错误当作“账号未启用”；一个状态查询失败不隐藏另一个可用因子。
- 导航状态、滚动引用由导航模块持有；关闭重置与用户持久化偏好分开处理。

## 无遗漏检查的口径

仓库根执行：

```sh
python3 scripts/check-business-file-size.py
python3 scripts/check-business-file-size.py --json
```

此次结果：**2,093 个自有生产源码文件，0 个超过 500 行，0 个未知类型超长文本**。
检查 Git 已跟踪及未跟踪、未忽略的文件；已删除文件不计入。
计数包含格式化后的注释、空行及导入，500 行允许，501 行失败。
覆盖 Go、Rust、TypeScript/JavaScript、Python、Shell、CSS、HTML、SQL 等源码与 shebang 脚本。
未识别扩展名的超长文本会使检查失败，必须明确分类，不能静默跳过。

41 个超长豁免文件属于测试、第三方依赖、生成路由、翻译提取数据或明确列出的验证脚本/夹具。
`--json` 输出每项路径和原因。不能仅通过随意新建 `vendor` 或 `tests` 目录绕开生产源码限制。
已知非程序数据格式、文档和二进制资产不属于本规则；Git 忽略的本地依赖和构建产物不属于版本化业务源码。

规则由根 `AGENTS.md` 引导到项目默认技能，CI 同时运行扫描器回归测试和全仓检查。
