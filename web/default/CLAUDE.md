# Claude Frontend Entry

在 `web/default` 内开始任何分析、命令执行或代码修改前，先阅读同级 `AGENTS.md`。

然后按任务范围继续：

- 需要选择本地技能时，读取 `.claude/skills.md`
- UI/UX 设计优先使用 `../../skills/frontend-design/SKILL.md` 或 `../../skills/product-designer/SKILL.md`
- React 性能相关使用 `../../skills/vercel-react-best-practices/SKILL.md`
- i18n 相关使用 `../../skills/i18n-translate/SKILL.md`
- shadcn/ui 相关使用 `../../skills/shadcn-ui/SKILL.md`

如果本目录规范与仓库根 `../../AGENTS.md` 冲突，先遵循更具体的本目录规范；涉及后端、部署、计费、provider、数据库时回到根规范。
